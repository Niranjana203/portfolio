# Niranjana Devi S — Data Engineer Portfolio

Responsive static portfolio personalized from the supplied resume. Built with HTML, CSS and vanilla JavaScript.

## Preview
Extract the ZIP and open `index.html` in a browser. No build tools are required.

## Verify before publishing
- Replace `YOUR_GITHUB_USERNAME` in `index.html` with the correct GitHub username/profile URL.
- Replace `assets/resume-placeholder.txt` with a PDF copy of your resume (for example, `assets/resume.pdf`) and update the Resume link in `index.html`.
- Confirm contact details and all dates/metrics before publishing.
- Add direct repository/demo links to projects and certificate verification links where available.
- Project visuals are illustrative; they are not real screenshots or live data charts.

## Deploy using GitHub Pages
1. Create a repository, for example `niranjana-portfolio`.
2. Upload all files and folders to the repository root, keeping `index.html` at the root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**, choose `main` and `/(root)`, and save.
5. Wait for GitHub Pages to publish. Copy the URL shown in the Pages settings.

Guide: https://docs.github.com/en/pages/quickstart

## Files
- `index.html` — page content
- `style.css` — responsive dark theme and animations
- `script.js` — mobile menu and reveal animations
- `assets/resume-placeholder.txt` — replace with your PDF resume

This is a static website. The email link opens the visitor's email application; no backend contact form is configured.
